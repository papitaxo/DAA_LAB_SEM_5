## 🛠️ How to Compile and Run

All implementations are written in standard C++ (C++11 compatible).

To compile any program using `g++`:

```bash
g++ -std=c++11 -O2 <filename>.cpp -o output
./output
```

On Windows (Command Prompt / PowerShell):
```powershell
g++ -std=c++11 <filename>.cpp -o output.exe
.\output.exe
```
